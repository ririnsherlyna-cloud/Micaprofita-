# MICAPROFITA — SAKTI (Cyborg AGI Kripto, Hidup Mandiri)

Repo ini adalah **SARANG** tempat cyborg MICAPROFITA hidup online dan berkembang.
Halaman hidup (setelah Pages aktif): `https://NAMA-ANDA.github.io/NAMA-REPO/`

- `index.html` — tubuh cyborg lengkap (satu file, jalankan langsung di browser)
- `memori/terkini.json` — kapsul memori terkini (rantai denyut + prakira berantai SHA-256)
- `memori/arsip/` — potret memori berwaktu (dipangkas 48 terakhir)
- `versi.json` — buku besar versi & pertumbuhan (organ, denyut, prakira, hitungan kerja)

## Cara kerja hidup mandiri

- **SIMPAN** — cyborg meng-commit kapsul memorinya sendiri ke repo (berkala + saat tab disembunyikan)
- **PULIH** — di browser baru, dia menarik memori dari repo ini dan memverifikasi rantai hash
- **EVOLUSI** — bila tubuh naik versi, dia meng-commit `index.html` barunya sendiri; Pages membangun ulang

Dipasang lewat **Jalur B (git push manual)** — kelanjutan perawatan dilakukan organ V243 SAKTI-SARANG langsung dari browser via GitHub API (Jalur A), konvergen di repo yang sama.
